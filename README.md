# Breast Cancer Diagnostic Prediction

## 📌 Problem Statement

The goal of this project is to build a machine learning model that can classify whether a tumor is **malignant or benign** based on diagnostic features.

## 🛠️ Tools Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Matplotlib
* Seaborn

## 🔄 Steps Performed

* Data loading and exploration
* Data cleaning and preprocessing
* Feature selection and scaling
* Model training using Logistic Regression and Random Forest
* Model evaluation using accuracy, precision, recall, and ROC-AUC

## 📊 Results / Insights

* The model achieved strong predictive performance on test data
* Important features were identified that influence tumor classification
* Logistic Regression provided a reliable baseline model for classification

## 🎯 Conclusion

This project demonstrates how machine learning can assist in early detection of breast cancer, improving diagnostic decision-making.
